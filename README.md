# ankdammen-legal

Static pages for Ankdammen's App Store Connect / Google Play Console submission fields:

- **Support URL** → `index.html`
- **Privacy Policy URL** → `privacy.html`
- Terms of use → `terms.html`

Published separately from the app's private source repo (`beerikss/Ankdammen`) purely so
GitHub Pages can serve it on the free tier, which requires a public repo. Contains no app
source code — just static HTML mirroring the legal copy from that repo's
`src/data/legal-content.ts`.

## Editing

`privacy.html` and `terms.html` are generated by `generate.js` from content copied out of
`src/data/legal-content.ts`. When that file changes in the main app, update the matching
`DOCS` entries here and re-run:

```
node generate.js
```

Bracketed text like `[Företagsnamn, org./FO-nummer, adress]` marks facts still missing —
replace them with the real values before submitting the app for review.

## Publishing

Served via GitHub Pages from the `main` branch root.
